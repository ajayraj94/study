A)
24  ✓ (Correct Answer)
B)
30
C)
36
D)
32
Correct Option: A) 24
Explanation:

According to the question:

Let, the unit place digit be: "x".

Let, the tens place digit be: "y".

Therefore, the number will be:

10y + x.

According to the question, this two-digit number is 4 times the sum of digits.

→ 10y + x = 4(x + y)

→ 10y + x = 4x + 4y

→ 6y = 3x

→ x = 2y ----(1).

Now, the new number is 18 more than the original if the digits are reversed.

→ (10x + y) - (10y + x) = 18

→ 9x - 9y = 18

→ x - y = 2 ----(2).

Putting the value of "x" from the equation (1) into equation (2):

→ 2y - y = 2

→ y = 2

Putting the value of "y" in equation (1):

→ x = 2 × 2

→ x = 4

As the tens digit is 2 and unit digit is 4.

The number is "24".

Hence, the correct answer is "24".
